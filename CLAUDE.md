# Instruções deste projeto para o Claude Code

## Autorização de commit/push

Pode fazer `git commit` + `git push` direto pra `main` sempre que o
trabalho estiver pronto, sem precisar pedir confirmação a cada vez —
permissão dada pelo usuário em 2026-09-27. Se algo parecer arriscado
(force push, rebase, reset destrutivo), aí sim confirme antes.
